# stock-analyze

유니스트 그릿인재 특기입증자료 증빙자료 (주식 리서치 프로그램)

이 저장소는 **제출한 자료의 프로그램을 직접 실행해 확인하실 수 있도록** 올린 것입니다.
아래는 설치와 실행 방법입니다.

---

## 가장 빠른 확인 — API 키 없이 3분

키 발급 없이 코드가 동작하는지 바로 확인하실 수 있습니다.

```bash
git clone https://github.com/GW123gg/stock-analyze.git
cd stock-analyze
pip install -r requirements.txt
python tests/run_tests.py
```

마지막 줄에 `결과: N/N 통과 — 전부 통과` 가 나오면 정상입니다. (약 5초, 인터넷·키 불필요. N 은 버전마다 늘어납니다)

전체 파일 구조와 각 파일이 무엇을 하는지는 **`CODEMAP.md`** 에 있습니다.

---

## 전체 실행 — API 키가 필요합니다

실제 데이터 수집·분석까지 돌리시려면 키 발급이 필요합니다. **모두 무료**이지만
한국 사이트 회원가입과 승인 대기(보통 즉시~1일)가 있습니다.

| 키 | 발급처 | 없으면 |
|---|---|---|
| DART | opendart.fss.or.kr | 공시 수집 불가 |
| 금융위 | data.go.kr | 시세·주식 정보 불가 |
| 한국은행 ECOS | ecos.bok.or.kr | 거시 지표 불가 |
| 네이버 검색 | developers.naver.com | 뉴스 일부 불가 |

키 파일 양식은 **`examples/`** 폴더에 있습니다.

```bash
copy examples\dart_api.txt.example dart_api.txt
```

복사한 뒤 `dart_api.txt` 를 열어 값을 채웁니다. 나머지 키도 같은 방식입니다.

키를 넣은 뒤:

```bash
python research_agent.py collect
python run_signals.py --check
```

## 저장소에 없는 것

- **API 키** (`*_api.txt`) — `examples/` 에 값이 빈 양식만 있습니다
- **이메일 주소** (`mail_config.txt`) — 양식만 있습니다
- **개인별 보유 종목·손익** — 개인정보라 어떤 형태로도 들어 있지 않습니다
- **매일 생성되는 산출물** (`output/`) — 리포트·캡처·예측 기록

`setup_kit/04_카이로스/` 의 압축파일도 실제 주소·토큰이 자리표시자로
바뀌어 있습니다. 값을 채우셔야 동작합니다.
