# 포트폴리오 등록 웹앱 설치 (Apps Script) — v11.13

친구들이 **각자 자기 포트폴리오를 직접 등록**하면, 매일 아침 **각자에게만** 보유 현황과
전략 메일이 가는 구조다. 사람 구분은 **이메일 주소**로 한다.

```
친구 → 웹 폼(이메일 확인 코드) → Google Sheet
                                    ↓ portfolio_sync.py (SECRET 필요)
                        portfolios/<이메일>.csv
                                    ↓ portfolio_review.py --all
                        아침 리서치가 사람별 전략 작성
                                    ↓ portfolio_mail.py --all --send
                        각자에게 자기 것만 발송
```

---

## 1. 웹앱 만들기 (10분, 한 번만)

★**파일이 2개다.** 코드와 화면을 나눠 뒀다 — 둘 다 넣어야 동작한다.

1. <https://script.google.com> → **새 프로젝트**
2. `Code.gs` 내용을 지우고 **`cowork/portfolio_webapp.gs` 전체를 붙여넣기**
3. 왼쪽 **파일 옆 `+` → HTML** → 이름을 정확히 **`index`** 로 짓고
   (`.html` 은 자동으로 붙는다) **`cowork/portfolio_webapp_index.html` 전체를 붙여넣기**
   - 기본으로 들어 있는 내용은 지우고 넣어라.
   - 이름이 `index` 가 아니면 첫 화면에서 바로 에러가 난다(`doGet` 이 이 이름으로 찾는다).
4. 맨 위 `var SECRET = '...'` 이 **길고 무작위한 값**인지 확인한다(이미 채워져 있으면 그대로 둔다).
   새로 만들려면 pc21 에서:
   ```bash
   python -c "import secrets; print(secrets.token_urlsafe(32))"
   ```
   바꿨으면 **`portfolio_sync_config.txt` 의 `secret=` 도 같은 값으로** 맞춰야 한다.
5. 저장 → **배포 → 새 배포 → 유형 '웹 앱'**
   - 설명: `포트폴리오 등록`
   - **실행: 나(본인 계정)**  ← 확인 코드 메일이 내 계정에서 나간다
   - **액세스 권한: 모든 사용자**  ← 친구들이 로그인 없이 쓸 수 있게
6. 권한 승인 화면이 뜬다 → "고급" → "안전하지 않은 페이지로 이동" → 허용
   (내가 만든 스크립트라 정상이다. 시트 읽기·쓰기와 메일 발송 권한을 요구한다)
7. 나오는 **웹 앱 URL**(`.../exec` 로 끝남)을 복사해 둔다.

★코드를 고칠 때마다 **배포 → 배포 관리 → 연필(수정) → 버전 '새 버전' → 배포**를 해야
  반영된다. 저장만 하면 배포본은 옛날 코드 그대로다(URL 은 그대로 유지된다).

> 스크립트를 시트에 바인딩하지 않아도 된다 — 첫 요청 때 "포트폴리오 데이터" 스프레드시트를
> 자동으로 만들고 그 ID 를 스크립트 속성에 저장해 계속 같은 시트를 쓴다.

## 2. pc21 연결

`portfolio_sync_config.txt` 를 채운다(이 파일은 `.gitignore` 가 막으므로 커밋되지 않는다):

```
url=https://script.google.com/macros/s/AKfy..../exec
secret=<웹앱의 var SECRET 과 똑같이 — 이미 채워져 있다>
```

확인:

```bash
python portfolio_sync.py --dry
```

- `SECRET 불일치` → 웹앱의 SECRET 과 config 의 secret 이 다르다.
- `응답이 JSON 이 아니다` → 배포 URL 이 틀렸거나(끝이 `/exec` 인지 확인) 액세스가 '모든 사용자'가 아니다.
- `0행 수신` → 아직 아무도 등록하지 않았다(정상).

## 3. 친구에게 줄 안내 (그대로 복붙해도 됨)

> 아래 링크에서 본인 이메일과 보유 종목을 등록하면, 매일 아침 그 메일로 보유 현황과
> 전략이 갑니다.
> **링크: (2단계에서 만든 URL)**
>
> - 이메일을 넣고 **확인 코드 받기** → 메일로 온 6자리를 입력 → 종목 추가
> - 종목코드는 6자리(앞의 0을 빼먹어도 자동으로 붙습니다)
> - **평단가**만 정확하면 됩니다. 매수일시는 받지 않습니다.
> - 같은 종목을 다시 추가하면 **덮어씁니다** — 물타기·불타기로 평단이 바뀌면 새 평단과
>   총수량을 다시 넣으세요.
> - 본인 메일로만 조회·수신됩니다. 남의 포트폴리오는 볼 수 없습니다.
> - 투자 판단과 책임은 본인에게 있습니다. 참고 자료입니다.

## 4. 매일 아침 (리서치가 자동으로 한다)

```bash
python portfolio_sync.py            # 웹앱 → portfolios/*.csv
python portfolio_review.py --all    # 사람별 측정
python portfolio_mail.py --all --send
```

## 설계상 지켜지는 것 (바꾸지 마라)

| 규칙 | 어디서 강제되나 |
|---|---|
| **A 의 포트폴리오는 A 에게만** | `portfolio_mail.py` 가 수신자를 `portfolios/<이메일>.csv` **파일명에서** 가져온다. 임의 주소로 보내는 인자가 없다 |
| **본인 등록 = 동의** | 웹앱이 그 주소로 확인 코드를 보내 소유를 확인한다. 남을 대신 등록하는 경로가 없다 |
| **남의 것을 볼 수 없다** | `action=mine` 은 코드 확인 후 자기 행만. 전량 조회(`action=all`)는 SECRET 필요 |
| **선행 0 이 안 죽는다** | 시트 저장 시 `'` 접두 + 읽을 때 양쪽에서 `normTicker_`/`normalize_ticker` |
| **중복 행이 안 쌓인다** | `add` 가 (이메일·종목·증권사) 기준 **덮어쓰기**. 안 그러면 물타기 재등록이 가중평균으로 계산돼 평단·수량이 틀어진다 |
| **동시 접속에도 안 깨진다** | 등록·삭제 전체가 `LockService` 안에서 실행 |
| **화면이 서버를 부를 수 있다** | `google.script.run`. 웹앱 화면은 googleusercontent 샌드박스 iframe 안이라 `fetch` 로 `/exec` 를 부르면 교차출처로 막힌다 |
| **확인 코드가 스팸에 안 쓰인다** | 같은 주소 60초 쿨다운 + 하루 60건 상한 |

## 한계 (알고 있어야 할 것)

- 확인 코드 메일은 **내 Gmail 할당량**을 쓴다(소비자 계정 하루 100통). 상한을 60으로 잡아둔
  이유다. 친구가 늘면 이 숫자를 조정하라.
- 웹앱 URL 을 아는 사람은 누구나 **자기 이메일로** 등록할 수 있다. 초대제로 막고 싶으면
  `handle_` 의 `add` 앞에 허용 이메일 목록 검사를 넣어라.
- 시트에 친구들의 보유 종목이 평문으로 쌓인다. **그 스프레드시트를 공유하지 마라.**
- **자동매매는 카이로스 계좌(내 것)에서만** 돈다. 친구들의 등록분은 KB 든 카이로스든
  전부 **참고용 판단**일 뿐이고, 어떤 주문도 그들 계좌로 나가지 않는다.
