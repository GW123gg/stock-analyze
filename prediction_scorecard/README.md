# prediction_scorecard — 예측 정답 채점 리포트

기존 분석 리포트(전체 방향성 위주)를 보완해, **과거 예측을 종목별·지수별로 "맞췄나/틀렸나" 채점**하는 별도 폴더입니다.
(기존 md 에 덧붙이지 않고 여기에 새 md 를 생성합니다.)

## 산출물
- **`예측채점_리포트.md`** — 자동 생성. 누적 적중률 + 날짜별 표(종목별 T+1·만기 등락률과 맞춤/틀림, 코스피·코스닥 방향 맞춤/틀림).

## 생성/갱신
```
python gen_scorecard.py
```
- 입력: `stock_research/output/_archive/*/predictions.json` + `output/*/predictions.json` (단 `_designtest`·`_discarded` 제외).
- 가격: `stock_backtest/price_cache`(FSC 공식종가→FDR, 캐시 재사용). 지수=KS11/KQ11.
- 채점: **픽=진입 후 상승이면 맞춤 / 숏=하락이면 맞춤 / 지수=방향 부호 일치면 맞춤.** 미만기(T+N이 미래)는 ⏳.
- **T+1 조기결과 + 만기(T+N) 결과**를 함께 표기 — 최근 예측도 T+1로 바로 확인 가능.

## 운용 팁
- **매일/회고 때 다시 돌리면** 미만기였던 항목이 만기되며 채워진다(누적 갱신).
- (선택) MCP-코워크 회고(review)에서 `python gen_scorecard.py`(shell=cmd)를 함께 실행하게 하면 자동 갱신.
- FSC 공식종가는 1일 지연이라 '오늘/어제'의 종가는 아직 None일 수 있다(다음날 채워짐).

## 현재 결과(예시, 갱신 시점에 따라 변동)
- 지수 KOSPI 방향 T+1 ~50% · KOSDAQ ~33%
- 픽(상승) T+1 ~44% · 숏(하락) T+1 ~78%/만기 100%
  → 백테스트에서 발견한 패턴(숏·방향 강, 단순 픽 약)과 일치.
