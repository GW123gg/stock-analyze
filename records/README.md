## 개인정보

- **이메일 주소·API 키·개인별 보유 종목은 들어 있지 않습니다.** 옮기기 전에 전수 검사했고
  (파일 138개), 이메일·토큰·보유수량·평단가·계좌번호 **0건**이었습니다.
- 회원별 포트폴리오 메일(`output/` 의 `portfolio_*` 파일)은 파일 이름 자체에 주소가 들어가
  있어 저장소에서 제외했습니다. `.gitignore` 와 커밋 훅(`tools/check_no_secrets.py`)이
  두 번 막습니다.
- 리포트 안의 종목·수치는 프로그램이 만든 추천과 그 채점 결과이며 개인 보유 내역이 아닙니다.

## 읽으실 때

- 이 출력은 **정보 정리이며 투자 자문이 아닙니다.**

- 같은 종목이 여러 날 추천되므로 행 수와 종목 수가 다릅니다.
