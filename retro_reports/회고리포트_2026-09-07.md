| 초과하락(alpha<0) | **30/71 = 42.3%** vs 코인플립 50% (p=0.2306) |
| ret_h 평균 | -4.01% |
| **D+4 커버 반사실** (짝맞춘 N=69) | **-2.39%** |
| **만기보유 ret_h** (★같은 69행) | **-3.72%** |
| (참고) 만기보유 ret_h 전체 71행 | -4.01% — ★D+4 와 **N이 달라 직접 비교 금지** |
| -9% 스톱 도달 | **32/71 pred 숏**, 도달일 실제 종가 평균 **-12.96%** |

- **무신호 유지 · Δ 숏 2행 -> 10회차 연속 불계상**. 방향적중 원값 단독 인용 금지(동어반복).
- ★**A42 반사실의 방향이 23회차 임계와 반대다**: **짝맞춘 69행**에서 D+4 커버(-2.39%)가
  만기보유(-3.72%)보다 **1.33%p 나쁘다** = 이 표본에서는 **일찍 덮는 것이 손해**다.
  행별로도 커버가 나은 행은 **23/69(33%)** 뿐이고 차이 중앙값 **+0.97%p**(양수=커버 열위)로
  평균·중앙·비율 3축이 모두 같은 방향이다. 23회차의 'D+4 커버' 임계는 같은 표본에서 나온
  in-sample 값이므로, **D+4 익절 규칙을 발행하지 않는다**(후보 등재까지만).
  ★초안은 커버 N=69 와 보유 N=71 을 빼서 1.62%p 로 적었다 — **N 불일치 정정**(§9 정정 4번).
- -9% 스톱은 도달일 실제 종가가 **-12.96%** — 갭 통과로 -9%보다 3.96%p 더 나쁘게 체결된다.
  '-9% 체결 가정' 금지 규약이 수치로 재확인됐다.
