# setup_kit — 전체 시스템을 세우는 데 필요한 것들

`stock-analyze` 의 파이썬 코드만으로는 매일 자동 실행이 되지 않습니다.
예정작업·메일 발송·화면 캡처 같은 주변 구성이 필요합니다.
이 폴더에 그 재료가 들어 있습니다.

**설치가 번거로우시면 [`AI_설치_프롬프트.md`](AI_설치_프롬프트.md) 를 보세요.**
AI 코딩 도구에 붙여넣을 프롬프트가 준비돼 있습니다.

---

## 폴더 안내

| 폴더 | 무엇 | 언제 필요한가 |
|---|---|---|
| `01_설치가이드/` | `SETUP.md`(설치 절차) · `CODEMAP.md`(파일별 역할 지도) | **맨 먼저** |
| `02_코워크_예정작업/` | 매일 아침 자동 실행 지시문·SKILL 정의 | 자동 실행을 붙일 때 |
| `03_터미널MCP/` | AI 가 이 PC 의 명령을 실행할 수 있게 하는 MCP 서버 | 예정작업이 파이썬을 돌리려면 |
| `04_카이로스/` | 별도 노트북에서 HTS 화면을 캡처하는 프로그램 | 공매도·대차잔고가 필요하면 |
| `05_앱스스크립트/` | 메일 발송·포트폴리오 등록 웹앱 코드 | 메일을 보내려면 |

## ★ 값이 지워져 있습니다

이 킷 안의 파일에는 **실제 이메일 주소·API 키·서버 주소가 들어 있지 않습니다.**
아래 자리표시자를 본인 값으로 바꿔야 동작합니다.

```
you@example.com                          → 본인 이메일
100.64.0.1                               → 본인 노트북의 테일넷 IP
REPLACE_WITH_YOUR_TOKEN                  → 본인이 만든 토큰
AKfycbREPLACE_WITH_YOUR_DEPLOYMENT_ID    → 본인 Apps Script 배포 ID
```

API 키 파일의 양식은 저장소 최상위 `examples/` 폴더에 있습니다
(`dart_api.txt.example` 처럼). 복사해서 `.example` 를 떼고 값을 채우세요.

## 세우는 순서

앞 단계가 끝나야 다음이 의미가 있습니다. **순서를 지켜 주세요.**

```
1. 파이썬과 라이브러리          ← 01_설치가이드/SETUP.md
2. API 키 발급 후 키 파일 작성   ← examples/ 의 양식
3. 수집기 1회 수동 실행로 확인    ← python run_signals.py --check
4. Apps Script 배포 (메일)      ← 05_앱스스크립트/
5. 터미널 MCP 설치              ← 03_터미널MCP/
6. 코워크 예정작업 등록          ← 02_코워크_예정작업/
7. (선택) 카이로스 노트북        ← 04_카이로스/
8. (선택) 웹사이트              ← 별도 폴더
```

3번에서는 파일이 생겼는지가 아니라 **파일 안의 날짜가 최근인지** 보세요.
`run_signals.py --check` 가 단계별로 `OK / STALE / EMPTY / FAIL` 을 찍어 줍니다.

## 환경 조건

- **윈도우 기준**입니다. 경로 구분자와 예정작업(작업 스케줄러)이 윈도우 전제로
  쓰여 있어, 리눅스에서는 그 부분을 바꿔야 합니다.
- **Python 3.12** 에서 확인했습니다.
- **API 는 전부 무료**입니다(DART·금융위·한국은행·네이버). 유료 결제가 필요한
  항목은 없습니다. 다만 AI 분석 단계에는 Claude 구독이 필요합니다.
- **카이로스 노트북은 선택**입니다. 없으면 공매도잔고·대차잔고가 '확인 불가'로
  남고 나머지는 동작합니다.
- 이 프로그램의 출력은 **정보 정리이며 투자 자문이 아닙니다.**
