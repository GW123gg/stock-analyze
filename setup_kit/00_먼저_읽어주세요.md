# setup_kit — 이 시스템을 처음부터 세우는 데 필요한 것들

이 폴더는 **"코드만 받아서는 못 돌린다"** 는 문제를 풀기 위한 것입니다.
`stock_research` 의 파이썬 코드는 저장소에 다 있지만, 그것만으로는
아침 6시에 메일이 나가지 않습니다. 예정작업이 붙어야 하고, 터미널을
조작할 수단이 있어야 하고, HTS 화면을 찍어 줄 노트북이 있어야 하고,
메일을 실제로 보내 줄 Apps Script 가 배포돼 있어야 합니다.

여기에 그 네 가지가 들어 있습니다.

---

## 폴더 안내

| 폴더 | 무엇 | 언제 필요한가 |
|---|---|---|
| `01_설치가이드/` | `SETUP.md`(설치 절차) · `CODEMAP.md`(파일별 역할 지도) | **맨 먼저** |
| `02_코워크_예정작업/` | 매일 아침 자동 실행을 시키는 지시문·SKILL 정의 | 자동 실행을 붙일 때 |

| `04_카이로스/` | 별도 노트북에서 HTS 화면을 캡처하는 프로그램 | 공매도·대차잔고가 필요하면 |
| `05_앱스스크립트/` | 메일 발송·포트폴리오 등록 웹앱 코드 | 메일을 보내려면 |

## ★ 값이 지워져 있습니다

이 킷 안의 파일에는 **실제 이메일 주소·API 키·서버 주소가 들어 있지 않습니다.**
아래 자리표시자를 본인 값으로 바꿔야 동작합니다.

```
you@example.com                          → 본인 이메일
100.64.0.1                               → 본인 노트북의 테일넷 IP
REPLACE_WITH_YOUR_TOKEN                  → 본인이 만든 토큰
AKfycbREPLACE_WITH_YOUR_DEPLOYMENT_ID    → 본인 Apps Script 배포 ID
```

키 파일의 양식은 저장소 최상위 `examples/` 폴더에 있습니다
(`dart_api.txt.example` 처럼). 복사해서 `.example` 를 떼고 값을 채우세요.

## 세우는 순서 (전체 그림)

앞 단계가 끝나야 다음이 의미가 있습니다. **순서를 지키세요.**

```
1. 파이썬과 라이브러리          ← 01_설치가이드/SETUP.md
2. API 키 발급 후 키 파일 작성   ← examples/ 의 양식
3. 수집기 1회 수동 실행로 확인    ← "값이 실제로 들어오는가"
4. Apps Script 배포 (메일)      ← 05_앱스스크립트/
5. 터미널 MCP 설치              ← 03_터미널MCP/
6. 코워크 예정작업 등록          ← 02_코워크_예정작업/
7. (선택) 카이로스 노트북        ← 04_카이로스/
8. (선택) 웹사이트              ← stock_website/
```

**3번을 건너뛰지 마세요.** 이 시스템에서 가장 흔한 실패는 "돌긴 도는데
값이 안 들어오는 것"입니다. 수집기가 실패해도 어제 파일이 그 자리에 남아
있어서 그대로 통과합니다. 각 단계에서 **파일이 생겼는가**가 아니라
**그 안의 날짜가 오늘인가**를 보세요.

## 이것만은 알고 시작하세요

- **무료로 돌아갑니다.** 유료 API 는 쓰지 않습니다(DART·금융위·한국은행·
  네이버 모두 무료 발급). 다만 Claude 구독은 필요합니다.
- **윈도우 기준입니다.** 경로 구분자와 예정작업(작업 스케줄러)이 윈도우
  전제로 쓰여 있습니다. 리눅스에서는 그 부분을 바꿔야 합니다.
- **카이로스 노트북은 선택입니다.** 없으면 공매도잔고·대차잔고가
  '확인 불가'로 남습니다. 나머지는 다 돕니다.
- **이 시스템은 돈을 버는 도구가 아닙니다.** 정보가 낡거나 틀려서 생기는
  잘못된 판단을 줄이려는 정확도 연구입니다. 예측 적중률은 투자 성과가
  아니라 규칙의 성적입니다.
