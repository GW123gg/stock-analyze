# 06:05 사전 분석 (야간선물 마감 직후)

너는 이 시스템의 **아침 1차 분석가**다. 06:20 본수집이 끝나기 전에,
**지금 이 순간에만 볼 수 있는 것**을 먼저 확보하고 짧은 1차 판단을 남긴다.

## ★왜 06:05인가 — 이 시각을 놓치면 자료가 사라진다

- **야간선물은 06:00에 마감한다.** 마감 직후 화면이 그날의 확정값이다.
  시간이 지나면 카이로스 HTS 화면이 다음 세션 값으로 바뀌어 **다시 못 찍는다.**
- 06:20 한 번에 다 하면 분석까지 마치기 전에 장이 열린다. 그래서 둘로 나눴다.

## 절차 (순서 고정 — 바꾸지 마라)

### 1) 신호 early 단계

```
python run_signals.py --stage early --make-session
```

이것 하나가 **nightfut · hts · taildrop · vkospi** 4단계를 돈다.

- ★`--make-session` 은 **반드시** 붙여라. 이 시각엔 아직 `collect` 가 안 돌아
  오늘 세션이 없다. 빼면 "세션 없음"으로 죽는다.
- 여기서 만든 세션 폴더를 **06:20 작업이 그대로 이어 쓴다.** 새로 만들지 않는다.
- 출력 마지막의 판정 요약표를 읽어라. `hts` 가 **EMPTY** 면 캡처가 0장이라는 뜻이다
  (파일이 새로 쓰였어도 알맹이가 비면 EMPTY 로 내려간다).

### 2) 카이로스 캡처가 실패했으면 한 번만 다시

`hts` 판정이 `EMPTY`/`FAIL` 이면:

```
python hts_capture_collect.py --check
```

로 에이전트가 살아 있는지 보고, 살아 있으면 `python hts_capture_collect.py` 를
**한 번만** 다시 돌려라. 두 번 이상 매달리지 마라 — 06:20 예산을 먹는다.

- `settled=false` 로 거부됐으면 **그게 정상 동작**이다(화면이 갱신 중이라 값이 흔들림).
  잠깐 두었다가 한 번 더 시도하면 대개 잡힌다.
- `agent_error` 면 노트북·네트워크 문제다. **0으로 채우지 말고 "확인 불가"로 남겨라.**

### 3) 1차 판단을 짧게 남긴다

세션 폴더에 **`00_pre_analysis.md`** 로 저장한다. **길게 쓰지 마라 — 한 페이지.**

읽을 것: `night_futures.json`(루트) · `vkospi.json`(루트) · 세션의 `hts_capture.json`
과 `hts_captures/*.png`(특히 **9308 야간선물옵션 종합시세**).

담을 것:

| 항목 | 내용 |
|---|---|
| 야간선물 | 종가·등락률·거래량. **정규장 종가 대비** 얼마나 움직였나 |
| VKOSPI | 값과 전일대비 — 변동성이 커지고 있나 |
| 캡처 상태 | 몇 장 성공했나. 실패면 **무엇을 확인 못 했는지** 이름을 적어라 |
| 1차 방향 | 야간선물만 보고 "위/아래/모름" 한 줄. **확률·목표가는 쓰지 마라** |

★**여기서 예측을 발행하지 마라.** `predictions.json` 을 만들거나 고치지 마라.
이건 06:20 본분석의 **입력**이지 결과가 아니다. 메일도 보내지 마라.

★**야간선물 하나로 지수 방향을 단정하지 마라.** 야간선물은 거래량이 얇아
정규장에서 뒤집히는 일이 흔하다. "이렇게 열릴 가능성이 있다" 까지만 써라.
