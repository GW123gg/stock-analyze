# AI 에게 설치를 맡기실 때 쓰는 프롬프트

설치가 번거로우시면, AI 코딩 도구에 아래 프롬프트를 **그대로 복사해 붙여넣으세요.**
AI 가 이 저장소를 읽고 설치·실행·확인까지 진행합니다.

**쓸 수 있는 도구** — Claude Code · GPT Codex · Cursor · Windsurf · GitHub Copilot Chat
(어느 것이든 "폴더를 읽고 명령을 실행할 수 있는" 도구면 됩니다)

---

## 준비 (1분)

1. 이 저장소를 내려받아 폴더로 풀어 둡니다
   ```
   git clone https://github.com/GW123gg/stock-analyze.git
   ```
   또는 깃허브 화면의 **Code → Download ZIP**
2. AI 도구를 열고 **그 폴더를 작업 폴더로 지정**합니다
   - Claude Code: 터미널에서 그 폴더로 이동한 뒤 `claude`
   - Cursor / Windsurf: **File → Open Folder** 로 그 폴더 열기
   - Codex: 그 폴더에서 실행
3. 아래 프롬프트를 붙여넣습니다

---

## 프롬프트 ① — 키 없이 동작만 확인 (권장, 3분)

> 대부분의 경우 이것으로 충분합니다. API 키 발급이 필요 없습니다.

```
당신은 지금 'stock-analyze' 라는 한국 주식 리서치 프로그램의 폴더에 있습니다.
저는 이 프로그램이 실제로 동작하는지 확인하려는 사람이고, 파이썬은 잘 모릅니다.

[목표]
API 키 없이 이 코드가 정상 동작하는지 확인하고, 결과를 저에게 쉬운 말로 설명해 주세요.

[해 주실 일]
1. 파이썬이 깔려 있는지 확인하세요 (python --version). 3.10 이상이면 됩니다.
   없거나 낮으면 어디서 받는지 알려만 주고 멈추세요. 직접 설치하지는 마세요.
2. pip install -r requirements.txt 를 실행하세요.
   일부 패키지가 실패해도 괜찮습니다 - 어떤 게 실패했는지만 기억해 두세요.
3. python tests/run_tests.py 를 실행하세요.
   "결과: 557/557 통과" 같은 줄이 나오면 성공입니다.
4. CODEMAP.md 를 읽고, 이 프로그램이 어떤 파일들로 이루어져 있는지
   5줄 이내로 요약해 주세요.

[보고 방식]
- 성공/실패를 있는 그대로 말해 주세요. 실패를 성공처럼 포장하지 마세요.
- 통과한 테스트 개수를 숫자로 알려 주세요.
- 오류가 났으면 그 오류 메시지와, 제가 무엇을 하면 되는지 알려 주세요.

[하지 말 것]
- 파일을 고치거나 새로 만들지 마세요. 저는 확인만 하려는 것입니다.
- 인터넷에서 무언가를 추가로 내려받아 설치하지 마세요.
- 제 컴퓨터 설정(환경변수·레지스트리·시작프로그램)을 바꾸지 마세요.
```

**여기까지 통과하면 코드가 정상이라는 뜻입니다.**
557개 검사는 인터넷도 API 키도 없이 도는 순수 계산 검증입니다.

## 프롬프트 ② — 실제 데이터 수집까지 (키 발급 필요, 30분~1일)

> 실제로 주식 데이터를 받아 보시려면 무료 API 키가 필요합니다.
> 한국 사이트 회원가입과 승인 대기가 있어 시간이 걸립니다.

```
당신은 지금 'stock-analyze' 라는 한국 주식 리서치 프로그램의 폴더에 있습니다.
저는 이 프로그램으로 실제 주식 데이터를 받아 보려고 합니다. 파이썬은 잘 모릅니다.

[목표]
API 키를 넣고 실제 수집이 되는 데까지 저를 안내해 주세요.

[해 주실 일]
1. 먼저 examples/ 폴더를 읽고, 어떤 키 파일이 필요한지 목록으로 알려 주세요.
   각 키를 어디서 받는지도 함께 알려 주세요(발급처 주소는 README.md 에 있습니다).
   ★키는 전부 무료입니다. 유료 결제가 필요한 것은 없습니다.

2. 제가 키를 받아 올 때까지 기다려 주세요. 키를 대신 발급받으려 하지 마세요.

3. 제가 "키 받았어요" 라고 하면, 어떤 파일에 어떻게 넣어야 하는지
   한 번에 하나씩 알려 주세요.
   - examples/dart_api.txt.example 을 dart_api.txt 로 복사
   - 그 파일을 열어 값을 채우기
   ★제가 키 값을 화면에 붙여넣으면 그 값을 다시 출력하지 마세요.

4. 키가 준비되면 아래를 순서대로 실행하고, 각 단계마다 결과를 알려 주세요.
   python research_agent.py collect
   python run_signals.py --check

5. run_signals.py --check 의 출력에는 단계별로 OK / STALE / EMPTY / FAIL 이
   찍힙니다. 무엇이 성공했고 무엇이 실패했는지 표로 정리해 주세요.

[중요한 규칙]
- 실패를 성공처럼 말하지 마세요. 데이터가 안 들어왔으면 안 들어왔다고 하세요.
- "파일이 만들어졌다"는 성공이 아닙니다. 파일 안의 날짜가 최근인지 확인해 주세요.
- 값이 비어 있는데 0 으로 채우지 마세요. '확인 불가'와 '0'은 다릅니다.

[하지 말 것]
- 메일 발송·자동매매와 관련된 스크립트는 실행하지 마세요.
- 제 키 값을 화면이나 로그에 출력하지 마세요.
- 제 컴퓨터 설정을 바꾸지 마세요.
```

## 프롬프트 ③ — 문제가 생겼을 때

> ①이나 ②에서 오류가 났을 때 쓰세요.

```
'stock-analyze' 폴더에서 아래 명령을 실행했더니 오류가 났습니다.

  [여기에 실행한 명령을 붙여넣으세요]

  [여기에 오류 메시지를 통째로 붙여넣으세요]

저는 파이썬을 잘 모릅니다. 아래대로 도와 주세요.

1. 이 오류가 무슨 뜻인지 쉬운 말로 설명해 주세요.
2. 제 환경 문제인지(파이썬 버전·패키지 누락 등),
   아니면 API 키가 없어서 그런 것인지 구분해 주세요.
3. 제가 할 수 있는 조치를 순서대로 알려 주세요.
4. 조치할 수 없는 문제라면 "이건 넘어가도 됩니다" 라고 분명히 말해 주세요.

★프로그램 코드를 고쳐서 오류를 없애지는 마세요.
  저는 원래 코드가 어떻게 동작하는지 보려는 것입니다.
```

## 자주 나오는 상황

| 증상 | 뜻 | 하실 일 |
|---|---|---|
| `python` 을 찾을 수 없음 | 파이썬 미설치 | [python.org](https://www.python.org/downloads/) 에서 3.12 설치. 설치 중 **"Add python.exe to PATH"** 체크 |
| `pip install` 중 일부 실패 | 선택 패키지 문제 | 테스트가 통과하면 넘어가셔도 됩니다 |
| 테스트는 통과, 수집은 실패 | 키가 없거나 잘못됨 | 정상입니다. 키 없이는 수집이 안 됩니다 |
| `세션을 찾지 못했다` | 아직 수집을 한 번도 안 함 | `python research_agent.py collect` 를 먼저 |
| 한글이 깨져 보임 | 윈도우 콘솔 인코딩 | `set PYTHONIOENCODING=utf-8` 후 다시 실행 |

## AI 에게 맡기실 때 알아 두실 점

- **AI 가 코드를 고치겠다고 하면 거절하세요.** 위 프롬프트에 "고치지 마세요" 를
  넣어 두었지만, 오류를 만나면 고치려 드는 경우가 있습니다. 원래 코드가 어떻게
  동작하는지 보시는 것이 목적이므로 수정은 필요하지 않습니다.
- **AI 가 "성공했습니다" 라고만 하면 숫자를 물어보세요.** "테스트 몇 개가
  통과했나요?" 처럼 물으시면 실제로 돌렸는지 확인됩니다.
- **API 키를 AI 에게 직접 주지 마세요.** 파일에 넣는 방법만 안내받으시고,
  값은 직접 입력하세요.
